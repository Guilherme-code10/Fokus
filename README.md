# 🎯 Fokus

Aplicação web de produtividade inspirada na técnica Pomodoro, desenvolvida durante meus estudos de JavaScript e Front-end.

O projeto permite organizar tarefas e alternar entre períodos de foco, descanso curto e descanso longo.

## 🚀 Funcionalidades

- ⏱️ Temporizador para períodos de foco
- ☕ Descanso curto e descanso longo
- ▶️ Iniciar e pausar o cronômetro
- 🎵 Música ambiente
- ✅ Cadastro de tarefas
- ✏️ Edição de tarefas
- 🎯 Seleção da tarefa em andamento
- ✔️ Conclusão da tarefa ao finalizar um período de foco
- 🗑️ Remoção de tarefas concluídas
- 🧹 Remoção de todas as tarefas
- 💾 Armazenamento das tarefas com LocalStorage
